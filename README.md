# social-assets

Bilder für geplante Social-Media-Beiträge von GuardAI und Belur Immobilien.

Metricool lädt die Bilder über jsDelivr und speichert eigene Kopien. So entstehen keine Netlify-Deploys für Social-Media-Bilder.

- Ordner: `guardai/<JJJJ-MM>/…` und `belur/<JJJJ-MM>/…`
- URL-Schema: `https://cdn.jsdelivr.net/gh/belurimmobilien/social-assets@main/<pfad>`
- Bestehende Dateien nicht überschreiben (jsDelivr cacht). Für Korrekturen einen neuen Dateinamen oder Ordner verwenden.
